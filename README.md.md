# AI-Generated Email Phishing Analysis

**Timeframe:** October – December 2025
**Domain:** Threat Analysis / Social Engineering

## Overview
An analysis comparing how effective AI-generated phishing emails are against phishing
written using traditional social engineering techniques, and what that shift means for
how organizations detect and defend against phishing.

## What I Did
- Analyzed the effectiveness of AI-generated phishing content compared to traditional
  social engineering techniques.
- Identified organizational security gaps and behavioral vulnerabilities that make
  phishing detection harder against AI-generated content specifically.
- Proposed a layered set of defenses: ML-based detection, behavioral analytics, and
  user training programs.
